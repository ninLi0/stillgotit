# Rubric for professionalism

Source: [Rubric for professionalism](https://61040.github.io/fa26/rubrics/professionalism/)

Downloaded: October 25, 2026

A professional submission should have these qualities:

- **Accessible.** A reader can use the submission as delivered, following clear, tested instructions. It is self-contained and does not rely on the author's machine or unstated knowledge. For code repositories, a fresh clone runs by following the README, without secrets or hardcoded local paths.

- **Organized.** The structure follows standard conventions, with a brief overview explaining the work and linking to its relevant parts. Nothing extraneous is included. For code repositories, the root directory is clean, and Git history shows incremental progress with meaningful commit messages.

- **Readable.** Everything is written for its human readers, with consistent naming and formatting and no placeholders or leftover drafts. For code repositories, dead code and debug output are removed, and any LLM-generated code has been reviewed and cleaned up.

Common pitfalls:

- **Hidden dependencies.** The submission relies on the author's machine, unavailable resources, or unstated setup.

- **Unreliable instructions.** Build, run, or test instructions are incomplete, out of date, or do not work.

- **Leftover material.** Placeholders, scratch files, abandoned drafts, dead code, or unreviewed generated material remain.

- **Missing orientation.** The individual parts are acceptable, but the overview does not explain the work or help readers find what matters.

Competency levels:

- **Deficient.** The submission cannot be used or understood without help from the author, or essential overview and instructions are missing.

- **Emergent.** There is some structure, but readers must guess or fix important details. Instructions are incomplete or out of date, or leftovers and inconsistencies are widespread.

- **Competent.** The submission can be used as documented. It is well organized and readable, with a clear overview, working instructions, and only minor leftovers or inconsistencies.

- **Expert.** The submission meets the competent criteria and is exceptionally easy to navigate, understand, and reproduce. Clear, reliable instructions make setup frictionless, and the overview quickly orients readers to the work.
